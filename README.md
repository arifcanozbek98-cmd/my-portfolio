## Features

### Responsive Design
The website is fully responsive and adapts to desktop, tablet, and mobile screens.

### Dark / Light Mode
Users can switch between dark and light themes.  
The selected theme is saved using **localStorage**.

### Mobile Navigation
A mobile-friendly navigation menu is included for smaller screens.

### Reveal Animations
Sections and cards appear smoothly on scroll using **Intersection Observer**.

### Active Navigation Highlight
The navigation bar updates automatically according to the visible section.

### Project Filtering
Projects can be filtered by category:
- All
- Web
- Python
- Data

### Back-to-Top Button
A floating button appears while scrolling to return quickly to the top of the page.
